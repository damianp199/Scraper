# Scraper 1.0

## Overview
This Scraper is a Python-based application designed to collect publicly available information about **kitesurfing courses in the Pomeranian Voivodeship (Poland)**. The program accesses selected web pages and extracts relevant data, including course information and pricing.

The collected data is saved locally in **JSON format** and can optionally be exported to a **MongoDB cloud database**.

Version **1.0** is the **first and only release** of this project.

# Program Functionality

After launching the program, the user can select one of **eleven supported cities** within the Pomeranian Voivodeship.

The application performs the following actions:

1. Searches the web using the keywords:
   - *kitesurfing*
   - *selected city*
   - *course*

2. Retrieves a list of kitesurfing schools from the regional tourism portal **pomorskie.travel**.

3. Extracts course-related data from selected web pages, including pricing information.

All extracted data is saved to a **JSON file located in the program directory**.

The scraping and parsing process uses the following technologies:

- **Scrapy**
- **Beautiful Soup**
- **Requests**

# Graphical Interface

The program displays **three separate windows**:

### 1. Search Results Window
Displays results generated by the search query combining:
- "kitesurfing"
- selected city
- "course"

### 2. School Listing Window
Displays a list of kitesurfing schools obtained from the regional tourism portal **pomorskie.travel**.

### 3. Scraped Data Window
Displays processed information extracted from selected web pages.  
The data is formatted for readability and reflects the **latest information available on the source pages**.

# Exporting Data to MongoDB

To upload the collected data to a **MongoDB cloud database**, follow these steps:

1. Locate the `Conditions()` function in the source code.
2. Uncomment all `Send(...)` class calls within this function.
3. In the `Send` class, update all **five instances** of the MongoDB client initialization with your connection string.

Example:

```python
client = MongoClient("mongodb+srv://user1:password1@scrapycluster.3ojmw.mongodb.net/ScrapyCluster?retryWrites=true&w=majority")
```

Replace the credentials and cluster details with your own **MongoDB Atlas connection string**.
